# Progression tracks Keys, not Characters

The app measures Key speed and records Mistakes for each Key. The app also unlocks Keys, not Characters. An accented character is not a separate unit: ά is the tonos key and then the α key.

This decision has three advantages:

- It agrees with the movements of the fingers.
- You practice the tonos key as one Key, not as seven accented vowels. Because almost all Greek words with two or more syllables have a tonos, the app unlocks the tonos key early.
- ς and σ stay separate Keys, because they are on different physical keys (W and S).

## Considered Options

- Measure each Character as a separate unit (ά, έ, ή …). This option adds 7–9 units to unlock. Also, you practice the movement of the tonos key in seven different units.
