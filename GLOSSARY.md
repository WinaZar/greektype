# GreekType

A personal trainer for touch typing on the macOS Greek keyboard layout. The trainer unlocks one Key at a time. It unlocks the next Key when all unlocked Keys are fast enough.

## Typing

**Key**:
A key of the Greek layout that the trainer measures and unlocks. The Keys are the lowercase letters (including ς), the tonos key, and the dialytika key.
_Avoid_: letter (for ΄ and ¨), button

**Character**:
A symbol in the text of a Lesson. You type a Character with one or more Keys. For example, you type ά with the tonos key and then the α key.
_Avoid_: glyph, letter

**Tonos key**:
The dead Key that puts a tonos on the next vowel (ά έ ή ί ό ύ ώ).

**Dialytika key**:
The dead Key that puts a dialytika on the next vowel (ϊ ϋ).

**Mistake**:
A press of an incorrect key. After a Mistake, the cursor does not move. The trainer records the Mistake for the expected Key.
_Avoid_: error, typo

## Practice

**Lesson**:
A text of about twelve real Greek words. You type the text from the start to the end.
_Avoid_: exercise, drill, test, session

**Lesson result**:
The speed (WPM) and the accuracy of one completed Lesson.

**Word pool**:
The real words that contain only unlocked Keys. The trainer makes each Lesson from these words.

**Focus key**:
The slowest unlocked Key. A Key without a measured speed is always the slowest. Lessons use the Focus key more frequently than other Keys.
_Avoid_: weak key

## Progression

**Unlocked keys**:
The Keys that the text of a Lesson can contain.
_Avoid_: active keys, enabled keys, learned keys

**Unlock order**:
The fixed sequence in which the trainer unlocks Keys. The most frequent Key in the word list is first.

**Key speed**:
The average speed of one Key, in WPM. The trainer measures the time from the previous keystroke to the correct press of this Key. This time includes the time of Mistakes.

**Target speed**:
The Key speed (35 WPM) that all unlocked Keys must have before the trainer unlocks the next Key.
